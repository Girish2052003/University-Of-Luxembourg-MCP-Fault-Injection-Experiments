# Tools used

**Author: Girish Nallan Chakravathy**

I used a coding agent to help with design, implementation, debugging, tests and documentation. I used Python, the official MCP SDK and pytest to run the local demonstration and checks. The demo uses fictional data and does not call a language model or paid API.

| Tool | Use |
| --- | --- |
| Coding agent | Design review, code, debugging, tests and documentation |
| Python and the official MCP SDK | Proxy, local tool server and test client |
| pytest | Automated checks of normal traffic, faults, logging and shutdown |
| Git and GitHub | Version history and delivery of the code and results |
| Official MCP documentation | Protocol and SDK compatibility details |

The saved demo logs and results were produced by running the program. The correctness check uses fixed reference values after the workflow finishes; those values are not given to the workflow to repair its answers.
